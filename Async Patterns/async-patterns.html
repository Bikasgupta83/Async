JavaScript Async Patterns

1. Debouncing

Wait until the user stops typing before executing.

2. Throttling

Execute a function at most once within a specific time.

3. Concurrency Control

Run only a limited number of async tasks simultaneously.

4. Retry Logic

Retry an operation when it fails.

5. Timeout Pattern

Stop waiting if an operation takes too long.

6. Sequential Execution

Execute async tasks one after another.

7. Parallel Execution

Execute independent async tasks together.
